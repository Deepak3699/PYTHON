# Day 1 - Python Introduction and Setup

## Python Kya Hai?
- Python ek programming language hai
- Isko 1991 mein Guido van Rossum ne banaya
- Yeh bohot simple aur easy to learn hai
- Real world mein use hota hai:
  * Web Development (Instagram, YouTube)
  * Data Science & AI
  * Automation
  * Game Development

## Python Kyun Seekhein?
- Simple English jesi language hai
- Bohot kam code mein kaam hota hai
- Job market mein bohot demand hai
- Free aur Open Source hai

## Installation Kaise Karein?

### Step 1: Python Download Karein
- Website: https://www.python.org/downloads/
- Latest version download karein
- Install karte waqt "Add Python to PATH" zaroor check karein ✅

### Step 2: VS Code Download Karein (Editor)
- Website: https://code.visualstudio.com/
- Install karein
- Python Extension install karein VS Code mein

### Step 3: Check Karein Python Install Hua Ya Nahi
- Terminal/CMD kholein
- Yeh type karein:
  python --version
- Agar version show ho gaya toh Python install ho gaya!

## Pehla Program - Hello World

### Code:
print("Hello, World!")

### Explanation:
- print() ek function hai
- Jo bhi () ke andar likhoge woh screen par show hoga
- "Hello, World!" ek text hai jise hum String kehte hain

## Comments Kya Hote Hain?
- Comments woh lines hain jo Python ignore karta hai
- Sirf programmer ke liye note likhne ke liye use hoti hain
- # sign se comment shuru hota hai

### Example:
# Yeh ek comment hai - Python yeh nahi padhega
print("Yeh print hoga")  # Yeh bhi comment hai

## print() Function Ke Features

### Multiple cheezein print karna:
print("Hello", "World")  # Output: Hello World

### Alag line mein print karna:
print("Pehli Line")
print("Doosri Line")

### Khali line print karna:
print()  # Sirf enter ki tarah kaam karta hai
