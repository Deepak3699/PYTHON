### Step 1: Python Download Karein
```bash

https://www.python.org/downloads/

# Windows par check karein:
python --version

# Mac/Linux par check karein:
python3 --version
```

### Step 2: Repository Clone Karein
```bash
# Git se clone karein:
git clone https://github.com/Deepak3699/PYTHON

# Folder mein jao:
cd PYTHON
```

### Step 3: Koi bhi file run karein
```bash
# Windows:
python Day_01/code.py

# Mac/Linux:
python3 Day_01/code.py
```

## 🔧 Common Errors Aur Solutions

```python
# Error 1: IndentationError
if True:
print("Hello")    # ❌ Galat - 4 spaces chahiye
    print("Hello") # ✅ Sahi

# Error 2: NameError
print(name)        # ❌ name define nahi kiya
name = "John"
print(name)        # ✅ Pehle define karo

# Error 3: TypeError
age = "25"
age + 5            # ❌ String aur int add nahi ho sakte
int(age) + 5       # ✅ Pehle convert karo

# Error 4: ZeroDivisionError
10 / 0             # ❌ Zero se divide nahi kar sakte
10 / 2             # ✅ Valid divisor use karo
```
